# Sistema Bancário com FastAPI e SQLite

Este projeto consiste no desenvolvimento de uma API REST para gerenciamento de operações bancárias, construída em Python com FastAPI e SQLite.

A aplicação implementa conceitos fundamentais de desenvolvimento backend, incluindo orientação a objetos, persistência de dados, tratamento de exceções, validação de entradas, controle transacional e arquitetura em camadas.

Entre as funcionalidades implementadas estão:

Cadastro de clientes
Criação de contas bancárias
Depósitos
Saques
Transferências entre contas
Consulta de extratos
Bloqueio e desbloqueio de contas
Persistência de dados em SQLite
Tratamento centralizado de exceções
Validação de requisições com Pydantic
API REST documentada automaticamente pelo FastAPI (Swagger)

O sistema foi projetado separando as regras de negócio da camada de API, seguindo boas práticas de desenvolvimento backend e proporcionando maior escalabilidade e manutenibilidade.
